# Лабораторная работа №2

**Тема:** Многостраничный сайт по регионам игры Genshin Impact.

**Страницы сайта:**
- `index.html` - обзор регионов
- `mondstadt.html` - Мондштадт
- `liyue.html` - Ли Юэ
- `inazuma.html` - Инадзума
- `archons.html` - таблица с архонтами регионов

## Как пользоваться сайтом

1. Откройте `lab2/index.html` в браузере.
2. На главной странице - приветствие и список регионов.
3. Через верхнее меню можно перейти на любую страницу:
   - **Главная** — обзор сайта;
   - **Мондштадт** — город свободы и ветра;
   - **Ли Юэ** — край контрактов и скал;
   - **Инадзума** — острова вечности;
   - **Архонты** — сводная таблица правителей регионов.
4. С каждой страницы региона можно вернуться к списку регионов по ссылке внизу текста.

## Особенности реализации

- Использованы блочные (`<header>`, `<nav>`, `<main>`, `<footer>`, `<ul>`, `<table>`) и строчные (`<a>`, `<span>`, `<strong>`, `<em>`) элементы.
- Все стили - в отдельном файле `style.css`, подключаются через `<link>`.
- Использованы 5 видов селекторов: по тегу, классу, id, потомку, псевдоклассу.
- Из цветов использованы следующие: фиолетовый (#3b2f5c, #5a4a85, #7c5cbf), бежевый (#f4f1ea), жёлтый акцент (#ffd76e).
- В таблице архонтов сделано разное выравнивание: `.table-left`, `.table-center`, `.table-right`.

# Лабораторная работа №3

**Тема:** Основы JavaScript.

**Цель:** изучение основ языка JavaScript, написание набора функций и закрепление навыков работы с Git.

## Что реализовано

В файле `src/core.js` реализованы следующие функции на JavaScript:
- `isInteger` — проверка числа на целостность.
- `even` — генерация массива четных чисел.
- `sumTo` — подсчет суммы чисел с помощью цикла.
- `recSumTo` — подсчет суммы с помощью рекурсии.
- `factorial` — вычисление факториала числа.
- `isBinary` — проверка, является ли число степенью двойки.
- `fibonacci` — нахождение N-го числа Фибоначчи.
- `getOperationFn` — создание функции-оператора с использованием замыканий.
- `sequence` — создание генератора арифметической последовательности (замыкания).
- `deepEqual` — рекурсивное сравнение двух объектов по их содержимому.
